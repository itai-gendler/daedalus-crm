# An account-owned native book cannot be adopted by another cloud identity

Native selection uses the authenticated cloud identity's bound directory. An eligible unclaimed directory may be adopted through the supported first-ownership path. Sign-out retains files. A remembered route is validated as a supported route but that validation alone does not establish that its subject record still exists.
