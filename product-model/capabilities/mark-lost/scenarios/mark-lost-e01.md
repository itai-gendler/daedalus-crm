# Undo can restore previous stage/probability

## Trigger

A CRM member invokes mark lost for the case “Undo can restore previous stage/probability”.

## Outcome

The loss action retains the previous opportunity stage and probability for its offered undo. Undo can restore those prior values; it does not infer an unrecorded lost-reason fact.
