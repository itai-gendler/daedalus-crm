# Mixed batch/already pooled/already scanned day

## Trigger

A CRM member invokes release to pool for the case “Mixed batch/already pooled/already scanned day”.

## Outcome

Manual mixed batches report changed, already-pooled and skipped counts; a fully unchanged batch creates no duplicate entry. A matching local-day receipt skips the page scan, while concurrent scans preserve per-row upsert fallback.
