# Manual release

## Trigger

A CRM member invokes release to pool for the case “Manual release”.

## Outcome

Released rows enter the pool with their current sales owner and stored last-change time retained. Already-pooled rows are unchanged; mixed batches report their actual released, unchanged and skipped counts.
