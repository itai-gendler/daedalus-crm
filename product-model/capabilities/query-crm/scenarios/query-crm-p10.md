# list_opportunities

## Trigger

The MCP client invokes query crm for the case “list_opportunities”.

## Outcome

list_opportunities returns up to thirty opportunities ordered by amount, with full totals separated by currency. Its default is OPEN; an unknown requested status falls back to OPEN. Stage labels and validated dates retain their existing meanings.
