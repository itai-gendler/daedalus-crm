# Follow-up apply conflict/duplicate/dependency outcome

## Trigger

A CRM member invokes accept draft for the case “Follow-up apply conflict/duplicate/dependency outcome”.

## Outcome

Repeated same-content communication confirmation within ten minutes refuses a duplicate apply. Ordinary save failure releases the reservation and keeps the card Proposed. If communication creation committed before latest-follow-up recalculation failed, the communication can remain despite the failed acceptance response.
