# Status apply conflict/duplicate/dependency outcome

## Trigger

A CRM member invokes accept draft for the case “Status apply conflict/duplicate/dependency outcome”.

## Outcome

A repeated same-content status confirmation within ten minutes is refused without applying again. A supplied comparison value that differs from the current selected status refuses the stale card. Failed apply releases its reservation and leaves the local card Proposed; no forced status overwrite is implied.
