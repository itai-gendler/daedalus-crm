# Invalid/skipped/duplicate/invisible matching rows

## Trigger

A CRM member invokes import customers for the case “Invalid/skipped/duplicate/invisible matching rows”.

## Outcome

Invalid rows, duplicates and inaccessible matching records are identified as skipped or failed in the reviewed import result. A refused row is not counted as a created or filled customer, and other eligible rows can still execute.
